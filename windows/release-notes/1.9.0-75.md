# Systinel 1.9.0 (Build 75) — Windows Preview

## English

### First installation

Download the single Windows x64 Setup.exe below and run it on Windows 10 22H2 or Windows 11 (Intel/AMD 64-bit). The runtime is included; no administrator account is required.

### Changes

Redesigned with Apple-inspired typography, spacing, a quiet sidebar and balanced light/dark cards. Fixed native system-tray registration: close to tray, click to reopen, live tooltip and update/quit menu. Added detected fan channels, manual PWM targets, adaptive temperature curves (45–90°C threshold, 5°C hysteresis), and optional game linking. Priority is game, manual, then automatic. Exit, disconnect, missing sensors, sleep and 95°C protection request firmware control; recoverable failures retry. Build 74 users can update through Settings → Software Update; preferences are preserved.

### Limitations

Hardware control requires explicit administrator approval once per app session, with no repeated prompts for that session’s switches. Some motherboards need the separately installed official PawnIO driver; Systinel does not install it. Closed OEM interfaces, pumps and channels without validated restore support remain read-only. PWM percentages are not RPM; only detected channels are offered. Hosted Windows checks cover installation, tray, real telemetry and simulated control/IPC recovery, not physical fan writes on your PC. Force-terminating the hardware helper is outside the recovery guarantee. No charge limits or Windows Authenticode certificate yet.

## Tiếng Việt

### Cài đặt lần đầu

Tải Setup.exe Windows x64 duy nhất bên dưới, chạy trên Windows 10 22H2 hoặc Windows 11 (Intel/AMD 64 bit). Đã kèm môi trường chạy, không cần tài khoản quản trị.

### Thay đổi

Thiết kế lại kiểu chữ, khoảng cách, thanh bên và thẻ sáng/tối theo thẩm mỹ Apple. Sửa đăng ký biểu tượng khay: đóng để chạy nền, nhấp mở lại, chỉ số và menu cập nhật/thoát. Kênh quạt nhận diện hỗ trợ PWM thủ công, đường cong nhiệt (ngưỡng 45–90°C, độ trễ 5°C) và liên kết game tùy chọn. Ưu tiên game, thủ công, tự động. Thoát, mất kết nối/cảm biến, ngủ hoặc 95°C sẽ yêu cầu trả điều khiển cho firmware và thử lại khi lỗi. Build 74 cập nhật tại Cài đặt → Cập nhật, giữ tùy chọn.

### Giới hạn

Mỗi phiên ứng dụng cần xác nhận quản trị một lần để kết nối phần cứng. Một số bo mạch cần tự cài driver PawnIO chính thức. Giao diện OEM đóng, bơm và kênh chưa xác minh khôi phục chỉ đọc. PWM không phải RPM. Kiểm tra Windows gồm cài đặt, khay, dữ liệu thực và khôi phục mô phỏng, không thay thử quạt vật lý trên từng PC. Buộc dừng thành phần phần cứng nằm ngoài bảo đảm khôi phục. Chưa có giới hạn sạc hoặc chứng chỉ Authenticode.
