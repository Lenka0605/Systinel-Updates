# Systinel 1.8.0 (Build 74) — Windows Preview

## English

### First installation

Download the single Windows x64 Setup.exe below and run it on Windows 10 22H2 or Windows 11 (Intel/AMD 64-bit). The runtime is included; no administrator account is required.

### Changes

First Windows preview: real CPU, memory, storage, disk I/O, network and process monitoring; tray, 12 languages, light/dark themes and three monitoring modes. Reversible background-app CPU priority optimization. Settings → Software Update checks the separate signed Windows preview feed, downloads and verifies the installer, then asks you to install. Preferences survive updates.

### Limitations

Temperature/fan readings require an existing compatible LibreHardwareMonitor WMI provider. Fan control and charge limits are not supported. No Windows code-signing certificate yet; Windows may report an unknown publisher. This is a preview, not full macOS feature parity.

## Tiếng Việt

### Cài đặt lần đầu

Tải Setup.exe Windows x64 duy nhất bên dưới, chạy trên Windows 10 22H2 hoặc Windows 11 (Intel/AMD 64 bit). Đã kèm môi trường chạy, không cần tài khoản quản trị.

### Thay đổi

Bản trải nghiệm Windows đầu tiên: giám sát CPU, bộ nhớ, lưu trữ, I/O, mạng và tiến trình thực; khay hệ thống, 12 ngôn ngữ, giao diện sáng/tối và ba chế độ. ## Bahasa Melayu

### Pemasangan pertama

Muat turun satu-satunya Setup.exe Windows x64 di bawah dan jalankan pada Windows 10 22H2 atau Windows 11 (Intel/AMD 64 bit). Runtime disertakan, akaun pentadbir tidak diperlukan.

### Perubahan

Pratonton Windows pertama: pemantauan CPU, memori, storan, I/O cakera, rangkaian dan proses sebenar; dulang, 12 bahasa, tema cerah/gelap dan tiga mod. ### Batasan

Sensor memerlukan penyedia WMI LibreHardwareMonitor serasi yang sedang berjalan. Tiada kawalan kipas atau had cas. Belum ada sijil tandatangan kod Windows; penerbit tidak dikenali mungkin dipaparkan. Tidak semua ciri macOS disediakan.
