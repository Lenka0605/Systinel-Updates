> 🌐 English · 简体中文 · 繁體中文 · Español · Français · Português (Brasil) · Русский · Deutsch · 日本語 · Tiếng Việt · 한국어 · Bahasa Melayu

## English

### Refined language selector materials

- The language selectors in the dashboard toolbar and menu panel now share a calmer material hierarchy in light and dark appearances.
- Reduced heavy borders, inner highlights, and shadows; the embedded selector now sits naturally within the panel.

### First installation

Download `Systinel-1.1.1-59.dmg`, open it, then drag Systinel to Applications. Existing users can install this release from Check for Updates inside Systinel.
