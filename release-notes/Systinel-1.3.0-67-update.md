# Systinel 1.3.0 (Build 67)

## English

### Enable System-Wide Optimization Now

- Immediately lower CPU and disk I/O scheduling priority for selected background apps and hide their windows to reduce compositing work. Restore when disabled or when Systinel quits.
- Supported browsers and chat apps receive lower background priority. Switching to an app restores it immediately. Exclude apps used for calls or downloads. Games, Riot and system processes are protected.
- Some operations could not complete. Check recovery status; unapplied changes are not counted as optimized.

### First installation

Download `Systinel-1.3.0-67.dmg`, open it, then drag Systinel to Applications. Existing users can install this release from Check for Updates inside Systinel.
