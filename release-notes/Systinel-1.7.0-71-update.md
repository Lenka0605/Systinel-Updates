# Systinel 1.7.0 (Build 71)

## English

- Fans speed up as temperature rises and slow gradually as it falls. System control resumes 5°C below the start temperature.
- Corrected temperature sensor mappings by chip generation; CPU and GPU averages and the hottest sensor are shown separately.
- Temperature control retries after protection; after a manual stop, use Resume cooling.
- Fixed the Settings title bar overlapping content.
- Approve the service upgrade once; subsequent toggles and speed changes need no repeated authorization.

### First installation

Download `Systinel-1.7.0-71.dmg`, open it, then drag Systinel to Applications. Existing users can install this release from Check for Updates inside Systinel.
