# Systinel 1.1.1 (Build 56)

> 🌐 English · 简体中文 · 繁體中文 · Español · Français · Português (Brasil) · Русский · Deutsch · 日本語 · Tiếng Việt · 한국어 · Bahasa Melayu

## English

### Clearer monitoring modes in the menu panel

- Simple now presents larger CPU, memory, and disk health rows, with only thermal and battery status below.
- Balanced uses a compact 2×2 CPU, GPU, memory, and disk overview and adds download activity.
- Professional keeps detailed progress rows and separate download and upload activity.
- Each mode now has a distinct accent while transitions continue to respect Reduce Motion. Your selected mode remains preserved after updates.

### First installation

Download `Systinel-1.1.1-56.dmg`, open it, then drag Systinel to Applications. Existing users can install this release from Check for Updates inside Systinel.

## Русский
