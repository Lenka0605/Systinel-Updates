# Systinel 1.8.0 (Build 73)

## English

- Desktop Macs now show a compact power-source card and AC/UPS status instead of missing-battery or paused-charging messages.
- Added the M1 HID temperature fallback to the app and fan service, while retaining automatic system cooling when safe readings are unavailable.
- Separated missing-sensor and high-temperature messages and added Copy fan diagnostics. The updated fan component requires administrator approval once.

### First installation

Download `Systinel-1.8.0-73.dmg`, open it, then drag Systinel to Applications. Existing users can install this release from Check for Updates inside Systinel.
