# Systinel 1.6.0 (Build 70)

## English

- Game optimization immediately runs fans at your chosen speed. Turning it off restores system control.
- Runs at the selected speed at the threshold; restores auto at 5°C below it. Works while Systinel is running.
- Game optimization takes priority. After turning it off or stopping manually, cooling must fall then rise before temperature control restarts.
- Refined the menu bar fan button with consistent rounding, colors and state feedback.

### First installation

Download `Systinel-1.6.0-70.dmg`, open it, then drag Systinel to Applications. Existing users can install this release from Check for Updates inside Systinel.
