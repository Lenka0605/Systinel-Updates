# Systinel 1.1.1 (Build 54)

> 🌐 English · 简体中文 · 繁體中文 · Español · Français · Português (Brasil) · Русский · Deutsch · 日本語 · Tiếng Việt · 한국어 · Bahasa Melayu

## English

### Performance update

- Reduced background CPU usage by separating fast counters from slower hardware queries.
- CPU and network data remain responsive, while storage capacity, battery details, memory, GPU, and disk I/O use demand-aware refresh intervals.
- The selected menu bar metric receives priority when the dashboard is hidden.
- Charging progress motion is preserved at a lower frame rate and pauses while the dashboard is not visible.

---

## 简体中文

### 性能优化

- 将实时计数器与低频硬件查询分层，降低后台 CPU 占用。
- CPU 与网络数据继续及时刷新；磁盘容量、电池详情、内存、GPU 和磁盘 I/O 改为按需更新。
- 仪表盘隐藏时，菜单栏当前选中的指标会优先刷新。
- 保留充电进度动效，但降低帧率，并在仪表盘不可见时暂停。

---

## 繁體中文

### 效能最佳化

- 將即時計數器與低頻硬體查詢分層，降低背景 CPU 使用率。
- CPU 與網路資料維持即時更新；磁碟容量、電池詳細資料、記憶體、GPU 和磁碟 I/O 改為按需更新。
- 儀表板隱藏時，選單列目前選取的指標會優先更新。
- 保留充電進度動畫，但降低更新頻率，並在儀表板不可見時暫停。
