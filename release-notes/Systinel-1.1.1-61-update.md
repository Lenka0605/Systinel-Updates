### Consistent menu-panel labels

- Monitoring, Language, Appearance, and Glass Transparency now use matching 12-point semibold labels and icon sizing.

Download `Systinel-1.1.1-61.dmg`, open it, then drag Systinel to Applications. Existing users can install this release from Check for Updates inside Systinel.
