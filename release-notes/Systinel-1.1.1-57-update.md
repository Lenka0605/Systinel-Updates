# Systinel 1.1.1 (Build 57)

> 🌐 English · 简体中文 · 繁體中文 · Español · Français · Português (Brasil) · Русский · Deutsch · 日本語 · Tiếng Việt · 한국어 · Bahasa Melayu

## English

### Clearer and more accessible monitoring modes

- Compact CPU, GPU, memory, and disk labels now keep their short visual form while VoiceOver announces the complete localized metric names and values.
- Simple-mode health rows have clearer boundaries in light and increased-contrast appearances. No extra sampling, timers, or continuous animations were added.

### First installation

Download `Systinel-1.1.1-57.dmg`, open it, then drag Systinel to Applications. Existing users can install this release from Check for Updates inside Systinel.
