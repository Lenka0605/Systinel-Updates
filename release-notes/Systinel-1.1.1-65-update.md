> 🌐 English · 简体中文 · 繁體中文 · Español · Français · Português (Brasil) · Русский · Deutsch · 日本語 · Tiếng Việt · 한국어 · Bahasa Melayu

## English

### Standard app window and Dock behavior

- Systinel windows now show their titles, including “Systinel” on the dashboard window.
- Systinel now behaves as a standard macOS app: its icon remains in the Dock and minimized windows are available there.

### First installation

Download `Systinel-1.1.1-65.dmg`, open it, then drag Systinel to Applications. Existing users can install this release from Check for Updates inside Systinel.
