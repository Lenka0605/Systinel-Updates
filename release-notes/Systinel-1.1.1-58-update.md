## English

### Smoother battery charging highlight

- The battery charging and charge-protection highlight now refreshes at up to 60 FPS for a visibly smoother sweep.
- The effect remains static when the dashboard is hidden or Reduce Motion is enabled.

### First installation

Download `Systinel-1.1.1-58.dmg`, open it, then drag Systinel to Applications. Existing users can install this release from Check for Updates inside Systinel.
