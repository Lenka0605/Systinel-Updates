# Systinel 1.1.1 (Build 60)

> 🌐 English · 简体中文 · 繁體中文 · Español · Français · Português (Brasil) · Русский · Deutsch · 日本語 · Tiếng Việt · 한국어 · Bahasa Melayu

## English

### Clearer professional-mode network speeds

- Professional mode now presents download and upload speeds side by side, matching the menu-bar layout.
- Each rate uses a fixed-width monospaced slot and larger type, so live values stay readable without shifting adjacent status items.

### First installation

Download `Systinel-1.1.1-60.dmg`, open it, then drag Systinel to Applications. Existing users can install this release from Check for Updates inside Systinel.
