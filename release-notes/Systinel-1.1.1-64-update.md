# Systinel 1.1.1 (Build 64)

> 🌐 English · 简体中文 · 繁體中文 · Español · Français · Português (Brasil) · Русский · Deutsch · 日本語 · Tiếng Việt · 한국어 · Bahasa Melayu

## English

### Unified controls and clearer battery details

- Language selectors now match Systinel’s segmented controls in height, width, and native glass material across the menu panel and dashboard header.
- Menu-panel setting labels now share one layout component, while battery labels and inactive values use larger, stronger text for better readability on tinted glass.

### First installation

Download `Systinel-1.1.1-64.dmg`, open it, then drag Systinel to Applications. Existing users can install this release from Check for Updates inside Systinel.
