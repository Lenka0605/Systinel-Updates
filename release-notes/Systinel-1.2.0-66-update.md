# Systinel 1.2.0 (Build 66)

> 🌐 English · 简体中文 · 繁體中文 · Español · Français · Português (Brasil) · Русский · Deutsch · 日本語 · Tiếng Việt · 한국어 · Bahasa Melayu

## English

- Prevent system idle sleep — Active only during a match; released after the match or when Systinel exits. Permanent power settings stay unchanged.

### One-click game optimization

- Added a dedicated Gaming section and a one-click action for League of Legends.
- When a match starts, Systinel automatically switches to 10-second sampling and pauses process scans, deep analysis, dashboard animation, and load alerts; everything restores after the match.
- Added checks for Apple Silicon and Metal, display refresh rate, power source, Low Power Mode, full-screen configuration, macOS Game Mode guidance, and the latest match's average FPS and frame-time spikes.
- Optimization uses supported macOS behavior only. It does not disable system security, terminate processes, or modify League of Legends files.

### First installation

Download `Systinel-1.2.0-66.dmg`, open it, then drag Systinel to Applications. Existing users can install this release from Check for Updates inside Systinel.
