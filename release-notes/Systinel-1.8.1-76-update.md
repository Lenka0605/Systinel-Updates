# Systinel 1.8.1 (Build 76)

## English

- Fixed the menu-bar panel reopening when the same indicator was clicked again. Each press now toggles once; clicking outside, switching apps, or pressing Escape while interacting with the panel dismisses it. Panel controls and their popovers remain usable.

### First installation

Download `Systinel-1.8.1-76.dmg`, open it, then drag Systinel to Applications. Existing users can install this release from Check for Updates inside Systinel.
