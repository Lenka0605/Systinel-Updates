# Systinel 1.4.0 (Build 68)

## English

### Fan control

- Runs fans at the hardware-reported maximum speed. Noise and power use will increase.
- Turning manual control off lets macOS set the speed or stop the fans based on temperature.
- Each start requires administrator approval. Quitting, sleep or connection loss restores automatic control.
- Requires an Apple silicon Mac with accessible fan controls. Fanless models are unsupported.

### First installation

Download `Systinel-1.4.0-68.dmg`, open it, then drag Systinel to Applications. Existing users can install this release from Check for Updates inside Systinel.

## Español

### Control de ventiladores

- Usa la velocidad máxima indicada por el hardware. Aumentan el ruido y el consumo.
- Al desactivar el control manual, macOS ajusta la velocidad o detiene los ventiladores según la temperatura.

## Русский

- Используется максимальная скорость по данным оборудования. Шум и расход энергии возрастут.

## Tiếng Việt

### Điều khiển quạt

- Quạt chạy ở tốc độ tối đa do phần cứng báo cáo. Tiếng ồn và điện năng sẽ tăng.
- Tắt điều khiển thủ công để macOS quyết định tốc độ hoặc dừng quạt theo nhiệt độ.
- Mỗi lần bật cần quyền quản trị. Thoát, ngủ hoặc mất kết nối sẽ khôi phục tự động.
- Cần Mac dùng chip Apple có quạt điều khiển được. Máy không có quạt không được hỗ trợ.

### Cài đặt lần đầu

Tải `Systinel-1.4.0-68.dmg`, mở tệp rồi kéo Systinel vào Applications. Người dùng hiện tại có thể cài bản này qua Kiểm tra bản cập nhật trong Systinel.

## 한국어

### 팬 제어

- 하드웨어의 최대 회전 속도로 냉각합니다. 소음과 전력 사용량이 증가합니다.
- 수동 제어를 끄면 macOS가 온도에 따라 속도 또는 정지를 결정합니다.
- 매번 관리자 승인이 필요합니다. 종료, 잠자기 또는 연결 끊김 시 자동 제어로 복원됩니다.
- 팬 제어가 가능한 Apple Silicon Mac이 필요합니다. 팬이 없는 모델은 지원하지 않습니다.
