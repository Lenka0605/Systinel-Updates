# Systinel 1.1.1 (Build 50)

> 🌐 English · 简体中文 · 繁體中文 · Español · Français · Português (Brasil) · Русский · Deutsch · 日本語 · Tiếng Việt · 한국어 · Bahasa Melayu

## English

### First installation

Download the only installer shown under “Assets” below:

`Systinel-1.1.1-50.dmg`

Open the DMG, then drag Systinel into Applications. If you already have Build 37 or later installed, you can check for updates directly in Systinel.

### What’s new

- NET keeps its wider fixed menu bar slot for simultaneous download and upload rates.
- CPU, GPU, MEM, Disk, and BAT now use compact fixed widths measured for their actual content instead of reserving NET-sized space.
- Percentage values use equal-width padding, so live updates remain perfectly stable inside each metric’s slot.

## 한국어

### 처음 설치

아래 “Assets”에서 하나의 설치 파일을 다운로드하세요:

- 백분율 값에 동일 너비 여백을 적용해 실시간 업데이트 중에도 각 영역에서 완전히 안정적으로 표시됩니다.

## Bahasa Melayu

### Pemasangan kali pertama

Muat turun satu-satunya fail pemasangan di bahagian “Assets” di bawah:

`Systinel-1.1.1-50.dmg`

Buka DMG, kemudian seret Systinel ke folder Applications. Jika Build 37 atau versi lebih baharu sudah dipasang, anda boleh menyemak kemas kini terus dalam Systinel.

### Perkara baharu

- NET mengekalkan ruang tetap yang lebih lebar pada bar menu untuk memaparkan kadar muat turun dan muat naik serentak.
- CPU, GPU, MEM, Disk dan BAT kini menggunakan lebar tetap yang padat berdasarkan kandungan sebenar, tanpa mengambil ruang sebesar NET.
- Nilai peratus menggunakan ruang isian sama lebar supaya kekal stabil sepenuhnya semasa kemas kini masa nyata.
