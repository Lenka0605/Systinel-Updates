# Systinel 1.7.1 (Build 72)

## English

- Refined the game optimization button with a compact layout and clear state feedback.
- Removed the Launch League of Legends button from game settings.
- Fixed missing text and icons in language, appearance, menu bar and monitoring selectors.

### First installation

Download `Systinel-1.7.1-72.dmg`, open it, then drag Systinel to Applications. Existing users can install this release from Check for Updates inside Systinel.
